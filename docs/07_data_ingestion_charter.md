# Phase 3 追補3: クリーンデータ収集・スクレイピング憲章（Data Ingestion Charter）

「家庭菜園・オーガニックAI（`niwa-lm`）」は、学習データの量や収集速度よりも、**「透明性・合法性・相手サーバーへの敬意」** を最優先事項と位置づけます。

本憲章は、データ取得パイプラインを実装・運用する際に遵守すべき技術的お作法と法的基準を定めたものです。

---

## 1. サーバーへの礼儀と技術的お作法（Politeness Engineering）

### 1.1 robots.txt の完全遵守
スクレイピングを行う際は、必ずドメイン直下の `robots.txt`（例: `https://example.com/robots.txt`）をパースし、`Disallow` 指定されたパスや `Crawl-delay` の指定を厳格に順守します。

### 1.2 アクセス頻度（Rate Limiting）
* 個別ページやAPIへのアクセスは、**最低 1.0 秒（推奨 2.0〜3.0 秒）以上のインターバル** を強制します。
* 相手サーバーのリソースを圧迫する並列スクレイピング（マルチスレッド・非同期の連打）は禁止します。

### 1.3 一括アーカイブの優先利用
* 青空文庫のように、公式または公認コミュニティ（aozorahack等）から「一括アーカイブ（全件ZIPやGitHubリポジトリ）」が提供されている場合は、Webサイトへの個別アクセスを行わず、アーカイブを利用します。

### 1.4 身元を明記した User-Agent
素性の分からないBotとしてアクセスすることを禁じます。必ずプロジェクト名、目的、リポジトリURLを含めた User-Agent を設定します。

```http
User-Agent: niwa-lm-crawler/0.1.0 (+https://github.com/KazutoMakino/my-mono-repo; Clean AI Educational Project)
```

## 2. 著作権と法的クリアランス基準

### 2.1 許容されるデータソース（グリーンリスト）
本プロジェクトで学習データとして取り込むことが許されるのは、以下のいずれかに該当するものに限定されます。

1. **パブリックドメイン（PD）**:
   * 著作者の死後70年（または旧法50年＋戦時加算）が経過し、著作権が完全に消滅した文学・文献（青空文庫など）。
2. **パブリックライセンス（オープンデータ）**:
   * **CC0**: いかなる権利も主張されない完全フリー。
   * **CC-BY**: 著作者のクレジット表示を遵守した上で利用。
   * **政府公的オープンデータ**: デジタル庁、e-Gov、国立国会図書館等で、営利・非営利を問わず二次利用が明示的に許諾されている文書。
3. **自己所有データ**:
   * 開発者自身が執筆したオリジナルの文章やコード。

### 2.2 排除対象（レッドリスト / 農薬・汚染データ）
以下のデータは、混入を完全に禁止します。

* **他社商用LLMの生成テキスト（合成データ / 蒸留）**:
  * モデル崩壊や近親交配、他社利用規約違反を回避するため完全排除。
* **利用規約でスクレイピングが禁止されているWebサイト**
* **権利関係が不透明なWebクローリングデータ（Common Crawl生データ等）**

## 3. 系譜台帳（Provenance Ledger）への義務的記録

取得したすべてのデータセットは、以下のメタデータを必ず系譜台帳に記録します。

```json
{
  "event_type": "DataIngestion",
  "payload": {
    "timestamp_utc": "2026-09-14T10:15:00Z",
    "source_name": "青空文庫: 中島敦『山月記』",
    "source_url_or_path": "https://ja.wikisource.org/wiki/山月記",
    "license": "Public Domain",
    "raw_data_sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
    "raw_data_bytes": 14250,
    "tokenized_sha256": "5566778899aabbccddeeff0011223344...",
    "num_tokens": 4621,
    "vocab_size": 782,
    "tokenizer_type": "Character-level (UTF-8)"
  }
}
```

この記録により、将来モデルが公開された際にも、**「このモデルは100%合法かつ礼儀正しく集められたデータのみで育った」** ことを誰に対しても胸を張って証明できます。
