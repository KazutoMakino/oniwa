> **検証環境**: Raspberry Pi 4 (Quad-Core ARM Cortex-A72 @ 1.5GHz, aarch64 Linux)  
> **実装**: Pure Rust (`oniwa-decide`), 外部MLフレームワーク一切不使用, Python/CUDAランタイム不使用。  
> **統計的信頼性**: 5つの独立乱数シード ($seed \in \{42, 1042, 2042, 3042, 4042\}$)、各構成計50回の実機推論。

---

## 1. エグゼクティブサマリー

本レポートは、`oniwa-decide` System One 意思決定エンジンにおける4構成のハードウェア効率とアーキテクチャ特性を総合比較したものです：
1. **Standard Baseline**: 実数Transformerバックボーン（4層, dim 128）＋ 実数決定ヘッド。
2. **Quaternion Head**: 実数Transformerバックボーン（4層, dim 128）＋ QuaternionDecisionHead（ヘッド4倍圧縮）。
3. **Full Q-Transformer**: 完全クォータニオンバックボーン（Q-Attention ＋ Q-SwiGLU）＋ QuaternionDecisionHead（コア約315Kパラメータ、埋め込み含め770K）。
4. **Iso-Parameter Real**: Full Q-Transformerと同等パラメータ数（約467K）に小型化した実数ベースライン。

## 3. 主要な実証所見

1. **4.01倍のレイテンシ短縮**:
   - **Full Q-Transformer** は、標準ベースライン（503.98 ms）に対して **125.66 ms** を達成し、**4.01倍の高速化** を実現しました。
2. **75.1%の消費エネルギー削減**:
   - 推論当たりエネルギーが **1.762 J** から **0.438 J** へと激減し、常時稼働エッジノードにおける発熱と電力負荷を大幅に低減しました。
3. **RSS メモリ消費の極小化**:
   - 常駐メモリサイズ（RSS）は **10.2 MB〜12.2 MB** に厳密に抑えられており、RAM容量 512MB〜1GB の低スペック環境でも極めて安定して動作可能です。
4. **System One vs System Two 速度比**:
   - `oniwa-lm` による 50トークン自己回帰逐次生成（24,073 ms）と比較し、Full Q-Transformer 意思決定は 128 ms で完了 — **188.4倍の高速化** と **105.8倍の情報エントロピー圧縮** を立証しました。
